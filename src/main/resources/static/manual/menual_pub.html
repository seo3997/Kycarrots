사용자는 각 지점의 모바일 상점(웹/앱)을 통해 편리하게 쇼핑하고 상품을 구매할 수 있습니다.

상점 접속 정보
- 접속 URL: http://amsa.asagong.com/
- 아이디: amsa@gmail.com

1. 쇼핑몰 진입 및 지점 선택

쇼핑몰에 접속하는 방법은 크게 두 가지가 있습니다.

  • 지점 선택 팝업 이용: http://www.asagong.com 상단의 [지점선택] 버튼을 클릭하면 나타나는 지점 리스트 팝업에서 원하는 지점을 선택하여 이동합니다.
  • 지점 직접 접속: 본사에서 부여받은 각 지점의 고유 도메인 주소(예: http://amsa.asagong.com)를 통해 지점 전용 쇼핑몰로 바로 진입할 수 있습니다.

2. 쇼핑 및 상품 탐색

지점 전용 메인 화면에서 카테고리별 상품을 확인하고, 실시간 인기 상품을 탐색합니다.

3. 상품 주문 및 결제

상품 상세 정보를 확인한 후, '구매하기' 버튼을 클릭하여 안전한 간편 결제를 진행합니다.

4. 배송지 관리

스마트한 주소록 관리
  • 기본 배송지 설정: 자주 사용하는 주소를 기본 배송지로 설정하여 결제 시 자동 입력
  • 최근 배송지 조회: 최근에 주문했던 주소를 선택하여 신속하게 주문 가능
  • 배송 메모 저장: "경비실에 맡겨주세요" 등 자주 쓰는 메모를 저장하여 재사용

5. 리뷰 및 상품 문의

구매한 상품에 대한 리뷰를 작성하거나 궁금한 사항을 직접 문의할 수 있습니다.

  • 포토 리뷰 작성: 구매 후 직접 촬영한 사진과 함께 소중한 경험을 공유
  • 1:1 상품 문의: 상품에 대한 궁금증을 남기면 지점/본사 관리자의 답변 수신

6. 주문 취소 및 반품

마이페이지에서 주문 상태에 따른 즉시 취소 및 반품 요청이 가능합니다.

  • 결제 즉시 취소: '결제완료' 상태인 경우 PG 자동 취소를 통해 즉시 환불 처리
  • 반품/교환 요청: 배송 완료 후 상품에 문제가 있을 경우 시스템을 통해 정식 요청

7. 실시간 배송 알림

본사에서 상품 배송을 시작하면 모바일 앱을 통해 "결제 완료! 배송 시작" Push 알림을 실시간으로 수신합니다.
