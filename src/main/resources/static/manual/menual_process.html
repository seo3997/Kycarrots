비즈니스 프로세스 요약

1. 사용자 권한 및 회원 구분

  • 본사운영: 시스템 전체 인프라 및 마스터 데이터를 관리하는 시스템 어드민 및 입금 확인, 배송 처리, 물류 담당
  • 판매지점: 독립 결제창을 운영하며 본사에 원가를 송금하는 지점 판매자
  • 일반사용자(구매자): 지점 앱/웹을 통해 물건을 구매하는 사용자

2. 지점 및 지점 관리자 등록 프로세스

본사 관리자가 지점 관리 메뉴에서 지점 정보(지점명, 토스 키 등)와 해당 지점을 운영할 관리자 계정 정보를 입력하여 지점을 생성합니다.

3. 지점별 상품 주문 및 결제

독립 정산 시스템

구매자는 특정 지점의 고유 도메인이나 앱을 통해 접속합니다. 각 지점은 자신만의 BRANCH_ID와 TOSS_CLIENT_KEY를 가지고 있어, 결제 시 해당 지점의 계좌로 직접 정산이 이루어지는 독립적인 상점 구조를 가집니다.

  • 지점별 전용 상점: 각 지점 판매자는 자신만의 마케팅 URL을 통해 고객을 유입시킵니다.
  • 안전한 직접 결제: 본사를 거치지 않고 지점별 토스 결제 키를 통해 즉시 결제가 처리됩니다.
  • 실시간 주문 연동: 모든 주문 내역은 본사 관리자 페이지와 해당 지점 관리자 페이지에 실시간으로 공유됩니다.

4. 정산 및 배송 관리

지점 판매자는 대시보드를 통해 본사에 입금해야 할 총 원가를 확인합니다. 본사 관리자가 입금 확인 및 배송 처리를 진행하면, 구매자에게 "결제 완료! 배송 시작" 알림이 발송됩니다.
