대시보드 주요 지표
  • 미처리주문: 입금 확인 전 단계의 신규 주문건
  • 지점미금액: 판매지점별 입금 확인 전 주문 금액의 총 합계
  • 오늘의 수금액: 금일 입금 처리 완료된 총 주문 금액
  • 배송중인주문: 현재 배송 프로세스가 진행 중인 주문

실시간 배송 처리 업무

지점 주문 목록에서 즉시 다음 업무를 수행할 수 있습니다.

  • 입금확인 송장 입력 후 클릭하여 배송 프로세스를 시작합니다.
  • 배송완료 최종 배송이 확인된 건을 종결 처리합니다.
  • 정보수정 이미 입력된 배송 정보를 갱신합니다.

지점 관리 시스템

신규 지점을 생성하고 지점별 고유 설정 및 정산 정보를 관리합니다.

2-1. 지점 리스트 및 조회

전체 지점의 운영 상태를 확인하며 지점 등록 버튼으로 진입합니다.

2-2. [신규 등록] 지점 등록

  • 지점 정보: 지점명, 지점코드(고유 식별값), 도메인 주소 입력
  • 결제 설정: 해당 지점의 토스 MID, 토스 시크릿키, 토스 클라이언트 키를 입력합니다. (토스 페이먼츠에서 발급받은 키 사용)
  • 배송비 설정: 배송비 관련 정보는 본사(Head Office)에서만 입력하며, 각 지점은 본사에서 설정한 배송비를 공통으로 사용합니다.
  • 등록 버튼으로 생성 완료

2-3. 정보 수정 및 상세

수정 버튼을 통해 기존 설정을 변경하거나 삭제할 수 있습니다.

사용자 권한 관리

본사 운영진 및 각 지점 판매자 계정을 관리합니다.

3-1. 관리자 계정 목록

3-2. [신규 등록] 계정 생성

  • 접속 정보: 로그인용 이메일 및 초기 비밀번호 설정
  • 권한 및 소속 설정:
    • 지점판매(ROLE_PROJ) 권한: 해당 계정이 관리할 지점 코드를 반드시 선택해야 합니다.
    • 본사(ROLE_SELL) 권한: 소속을 본사로 선택하여 시스템 전체 관리 권한을 부여합니다.
  • 등록 버튼으로 최종 생성

3-3. 계정 정보 상세

특정 관리자의 상세 프로필과 현재 부여된 권한을 확인합니다.

  • 목록에서 이메일 또는 이름을 클릭하여 상세 화면으로 진입합니다.
  • 부여된 권한(ROLE_SELL/PROJ)과 소속 지점 정보를 확인합니다.

3-4. 계정 정보 수정 및 삭제

기존 관리자의 정보를 업데이트하거나 시스템 이용 권한을 제어합니다.

  • 정보 업데이트: 성명, 연락처, 비밀번호 등을 수정한 후 수정 버튼을 클릭하여 저장합니다.
  • 계정 삭제: 운영에서 제외된 관리자는 삭제 버튼을 통해 영구 제거합니다.

상품 마스터 관리

플랫폼 판매 상품의 전체 데이터를 제어합니다.

4-1. 상품 목록 및 조회

4-2. [신규 등록] 상품 등록

  • 가격 정보: 판매가 및 원가 정보를 정확히 입력
  • 이미지 구성: 대표 이미지를 지정하여 리스트 노출 이미지 설정
  • 등록 버튼으로 저장

4-3. 상품 상세 수정 및 상태 변경

  • 상태변경: 즉시 품절 처리하거나 판매를 재개합니다.
  • 수정: 상세 내역을 업데이트합니다.

4-4. 리뷰 및 문의 대응

고객의 소중한 피드백에 대해 답변을 등록하고 관리합니다.

주문 및 통합 배송

전체 지점의 주문 내역을 실시간으로 추적하고 통합 배송 관리를 수행합니다.

5-1. 통합 주문 조회

5-2. 주문 상세 및 배송 처리

  • 입금확인: 배송 정보 입력 후 클릭 (상태: 배송중)
  • 배송완료: 최종 도착 확인 시 클릭 (상태: 배송완료)
  • 정보수정: 오입력된 송장번호를 즉시 수정

시스템 설정 및 게시판

시스템 공지사항 및 기본 환경을 설정합니다.

6-1. [신규 등록] 공지사항 관리

등록 버튼으로 신규 공지를 게시합니다.
