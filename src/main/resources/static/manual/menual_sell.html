본사 운영 관리자 메뉴얼

본사 관리자는 시스템의 핵심 데이터를 관리하며 지점 생성, 상품 관리, 주문 처리를 담당합니다.

1. 메인 화면 (대시보드)

로그인 후 첫 화면으로 본사 운영의 핵심 지표를 실시간으로 모니터링합니다.

1-1. 대시보드 상세 업무
  • 미처리주문: 판매지점에서 발주했으나 아직 입금 확인이 되지 않은 주문건
  • 지점미금액: 판매지점별 입금 확인 전 주문 금액의 총 합계
  • 오늘의 수금액: 금일 입금 확인 처리가 완료된 총 주문 금액
  • 배송중인주문: 배송은 시작되었으나 아직 배송 완료 처리가 되지 않은 주문
  • 지점주문List: 전 지점에서 발생한 실시간 주문 목록 확인 (주문번호 클릭 시 상세 화면 이동)
  • 입금확인 택배사 및 운송장 번호 입력 후 클릭하면 주문 상태가 '배송중'으로 변경됩니다.
  • 배송완료 택배사에서 구매자에게 물품 전달이 완료된 후 클릭하여 전체 주문 프로세스를 종결합니다.
  • 정보수정 이미 배송 중인 주문의 택배사 정보를 변경하거나 오입력된 운송장 번호를 수정할 때 사용합니다.
1-2. 시스템 상태 코드 정의

주문 상태 코드

  • 10 결제대기
  • 20 결제실패
  • 30 결제완료
  • 40 주문취소
  • 50 배송준비중
  • 60 배송중
  • 70 배송완료
  • 99 주문확정

결제 상태 코드

  • 10 결제대기
  • 20 결제실패
  • 30 결제완료
  • 40 결제취소

지점 입금 상태 코드

  • 10 입금대기 (미처리)
  • 20 입금확인요청
  • 30 입금완료

2. 지점 관리

신규 지점을 생성하고 지점별 고유 설정 및 정산 정보를 관리합니다.

2-1. 지점 리스트 및 조회

전체 지점의 운영 상태를 확인합니다. 지점 등록 버튼으로 등록 화면으로 진입합니다.

2-2. [신규 등록] 지점 등록

시스템에 새로운 판매 지점을 생성합니다.

  • 지점 정보: 지점명, 지점코드(고유 식별값), 도메인 주소를 입력합니다.
  • 결제 설정: 해당 지점에서 사용할 Toss Payments 등의 PG API 키를 등록합니다.
  • 등록 버튼을 클릭하여 생성을 완료합니다.

2-3. 지점 정보 수정 및 상세

지점명을 클릭하여 상세 정보를 확인하고, 수정 버튼을 통해 기존 설정을 변경하거나 삭제할 수 있습니다.

3. 사용자 관리

운영진 및 지점 판매자 계정을 관리합니다.

3-1. 관리자 계정 목록

3-2. [신규 등록] 계정 생성

등록 버튼을 통해 신규 운영자를 추가합니다.

  • 로그인 정보: 접속 계정(이메일)과 초기 비밀번호를 설정합니다.
  • 권한 및 소속: 본사(ROLE_SELL) 또는 특정 지점(ROLE_PROJ) 소속 여부를 지정합니다.
  • 확인 버튼으로 계정 생성을 완료합니다.

4. 상품 관리

판매 상품의 전체 라이프사이클을 관리합니다.

4-1. 상품 마스터 리스트

4-2. [신규 등록] 상품 등록

상품 등록 버튼을 클릭하여 판매할 상품을 시스템에 등재합니다.

  • 기본 정보: 상품명, 카테고리, 판매 가격, 원가 정보를 입력합니다.
  • 이미지 관리: 대표 이미지 및 상세 이미지를 업로드하고 대표지정을 설정합니다.
  • 판매 옵션: 사이즈, 색상 등 구매자가 선택할 옵션 항목을 구성합니다.
  • 등록 버튼으로 최종 저장합니다.

4-3. 상품 상세 정보 수정

수정을 통해 정보를 업데이트하거나, 상태변경 버튼으로 판매 여부를 즉시 제어합니다.

5-1. 통합 주문 목록

5-2. 주문 상세 및 배송 처리

주문 상세 화면에서 실질적인 배송 업무를 처리합니다.

  • 입금확인: 배송 정보(택배사, 송장번호) 입력 후 클릭하여 배송을 시작합니다.
  • 정보수정: 오입력된 배송 정보를 수정합니다.
  • 배송완료: 최종 배송 완료 시 클릭하여 주문을 종결합니다.

6-1. [신규 등록] 공지사항 및 게시물
