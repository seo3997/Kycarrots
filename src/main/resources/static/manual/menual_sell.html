1. 메인 화면 (대시보드)

로그인 후 첫 화면으로 본사 운영의 핵심 지표를 실시간으로 모니터링합니다.

대시보드 상세 업무
  • 미처리주문: 판매지점에서 발주했으나 아직 입금 확인이 되지 않은 주문건
  • 지점미금액: 판매지점별 입금 확인 전 주문 금액의 총 합계
  • 오늘의 수금액: 금일 입금 확인 처리가 완료된 총 주문 금액
  • 배송중인주문: 배송은 시작되었으나 아직 배송 완료 처리가 되지 않은 주문
  • 지점주문List: 전 지점에서 발생한 실시간 주문 목록 확인
  • 입금확인 처리: 택배사 및 운송장 번호 입력 후 '배송시작' 클릭 시 상태 변경
