1. 메인 화면 (대시보드)

로그인 후 첫 화면으로 본사 운영의 핵심 지표를 실시간으로 모니터링합니다.

1-1. 대시보드 상세 업무
  • 미처리주문: 판매지점에서 발주했으나 아직 입금 확인이 되지 않은 주문건
  • 지점미금액: 판매지점별 입금 확인 전 주문 금액의 총 합계
  • 오늘의 수금액: 금일 입금 확인 처리가 완료된 총 주문 금액
  • 배송중인주문: 배송은 시작되었으나 아직 배송 완료 처리가 되지 않은 주문
  • 지점주문List: 전 지점에서 발생한 실시간 주문 목록 확인 (주문번호 클릭 시 상세 화면 이동)
  • 입금확인 택배사 및 운송장 번호 입력 후 클릭하면 주문 상태가 '배송중'으로 변경됩니다.
  • 배송완료 택배사에서 구매자에게 물품 전달이 완료된 후 클릭하여 전체 주문 프로세스를 종결합니다.
  • 정보수정 이미 배송 중인 주문의 택배사 정보를 변경하거나 오입력된 운송장 번호를 수정할 때 사용합니다.
1-2. 시스템 상태 코드 정의

주문 상태 코드

  • 10 결제대기
  • 20 결제실패
  • 30 결제완료
  • 40 주문취소
  • 50 배송준비중
  • 60 배송중
  • 70 배송완료
  • 99 주문확정

결제 상태 코드

  • 10 결제대기
  • 20 결제실패
  • 30 결제완료
  • 40 결제취소

지점 입금 상태 코드

  • 10 입금대기 (미처리)
  • 20 입금확인요청
  • 30 입금완료

2. 지점 관리

신규 지점을 생성하고 지점별 고유 설정 및 정산 정보를 관리합니다.

2-1. 지점 리스트 (조회)

전체 지점의 운영 상태와 도메인 정보를 확인합니다.

  • 검색 특정 조건의 지점을 검색합니다.
  • 지점 등록 새로운 판매 지점을 생성하기 위한 등록 화면으로 이동합니다.

2-2. 지점 등록 및 수정 (상세)

지점 고유 코드, PG 결제 키(Toss 등), 관리자 정보 및 도메인을 입력합니다.

  • 수정 상세 화면에서 정보 수정 모드로 전환합니다.
  • 확인/등록 입력한 정보를 저장하거나 신규 지점을 생성합니다.
  • 삭제 해당 지점 정보를 시스템에서 제거합니다.

3. 사용자 관리

본사 운영자와 각 지점의 판매자 계정을 관리하고 권한을 제어합니다.

3-1. 관리자 계정 목록

현재 등록된 모든 관리자 계정을 조회합니다.

  • 검색 아이디나 이름으로 계정을 찾습니다.
  • 초기화 검색 조건을 초기 상태로 되돌립니다.
  • 등록 신규 계정 추가 화면으로 이동합니다.

3-2. 계정 상세 및 설정

이메일, 권한(ROLE_SELL, ROLE_PROJ) 등을 설정합니다.

  • 수정 계정 정보를 변경합니다.
  • 삭제 계정을 비활성화하거나 삭제합니다.

4. 상품 관리

플랫폼에서 유통되는 모든 상품의 마스터 데이터를 관리합니다.

4-1. 상품 마스터 리스트

  • 검색 상품명이나 코드로 검색합니다.
  • 상품 등록 신규 상품을 등록합니다.

4-2. 상품 등록 및 정보 수정

  • 미리보기 사용자 화면에 노출될 모습을 사전에 확인합니다.
  • 상태변경 상품의 노출 상태(판매중/품절 등)를 즉시 변경합니다.
  • 대표지정 여러 이미지 중 메인 노출 이미지를 선택합니다.
  • 수정 상품 상세 내역을 업데이트합니다.
  • 삭제 상품을 시스템에서 영구 삭제합니다.

4-3. 상품 리뷰 및 문의(Q&A) 관리

지점 고객이 남긴 리뷰를 확인하고, 문의 사항에 대해 답변을 진행합니다.

  • 답변 고객 문의에 대해 공식 답변을 등록합니다.
  • 복구 관리자에 의해 숨겨진 리뷰를 다시 노출합니다.
  • 삭제 부적절한 게시물을 제거합니다.

5. 주문 및 통합 배송 관리

전 지점의 실시간 주문 내역을 통합하여 관리하고 배송 프로세스를 처리합니다.

5-1. 통합 주문 목록

전체 주문 건에 대한 결제 및 배송 상태를 모니터링합니다.

  • 검색 주문번호, 수령인 등으로 주문을 추출합니다.
  • 상세 클릭 시 주문 상세 정보 화면으로 이동합니다.

5-2. 주문 상세 및 배송 처리 (상세)

  • 입금확인 송장번호 입력 후 '배송중' 상태로 전환합니다.
  • 배송완료 물품 전달 완료 후 주문을 종결 처리합니다.
  • 정보수정 이미 입력된 송장 정보를 수정하거나 택배사를 변경합니다.
  • 주문취소 결제 취소 API를 호출하여 주문을 무효화합니다.

6. 시스템 설정 및 기타 관리

공지사항 관리 및 시스템 운영에 필요한 공통 설정을 담당합니다.

6-1. 게시판 및 공지사항

본사 및 지점 관리자들에게 공유할 주요 공지사항을 등록하고 관리합니다.
