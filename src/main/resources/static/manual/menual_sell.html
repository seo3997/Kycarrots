지점 관리

신규 지점을 생성하고 지점별 고유 설정 및 정산 정보를 관리합니다.

2-1. 지점 리스트 및 조회

전체 지점의 운영 상태를 확인하며 지점 등록 버튼으로 진입합니다.

2-2. [신규 등록] 지점 등록

  • 지점 정보: 지점명, 지점코드(고유 식별값), 도메인 주소 입력
  • 결제 설정: 해당 지점의 **토스 API 키**를 입력합니다.
  • 배송비 설정: 본사 배송 정책을 공통으로 사용하므로 본사만 입력합니다.
  • 등록 버튼으로 생성 완료

2-3. 지점 상세 정보

특정 지점의 상세 설정값과 도메인 정보를 확인합니다.

  • 수정 버튼 클릭: 지점 정보를 변경하는 화면으로 이동합니다.
  • 삭제 버튼 클릭: 해당 지점 정보를 시스템에서 제거합니다.

2-4. 지점 정보 수정

지점의 API 키 또는 배송 정책 등을 업데이트합니다.

  • 정보 변경 후 수정 버튼을 클릭하여 저장합니다.
  • 취소 버튼 클릭 시 변경사항을 저장하지 않고 상세 화면으로 복귀합니다.

사용자 권한 관리

본사 운영진 및 각 지점 판매자 계정을 관리합니다.

3-1. 관리자 계정 목록

3-2. [신규 등록] 계정 생성

  • 접속 정보: 로그인용 이메일 및 초기 비밀번호 설정
  • 권한 및 소속 설정:
    • 지점판매(ROLE_PROJ) 권한: 해당 계정이 관리할 지점 코드를 반드시 선택해야 합니다.
    • 본사(ROLE_SELL) 권한: 소속을 본사로 선택하여 시스템 전체 관리 권한을 부여합니다.
  • 등록 버튼으로 최종 생성

3-3. 계정 정보 상세

특정 관리자의 상세 프로필을 확인하고 관리 액션을 수행합니다.

  • 수정 버튼 클릭: 정보를 변경할 수 있는 **사용자 수정** 화면으로 이동합니다.
  • 삭제 버튼 클릭: 해당 계정을 시스템에서 즉시 제거합니다.
  • 목록 버튼 클릭: 이전 사용자 리스트 화면으로 돌아갑니다.

3-4. 계정 정보 수정

실제 데이터를 기반으로 관리자 정보를 업데이트합니다.

  • 정보 업데이트: 성명, 연락처, 권한 등을 변경한 후 화면 하단의 확인 버튼을 클릭하여 저장합니다.
  • 작업 취소: 취소 버튼을 클릭하면 변경사항을 저장하지 않고 이전 상세 화면으로 돌아갑니다.

상품 관리

플랫폼 판매 상품의 전체 데이터를 제어합니다.

4-1. 상품 목록 및 조회

현재 판매 중인 상품 리스트를 확인하고 상품 등록을 시작합니다.

4-2. [신규 등록] 상품 등록

  • 기본 정보: 상품명, 카테고리, 판매가, 원가 입력
  • 에디터 사용법:
    • 에디터 모드는 **Summernote, Raw HTML, Plain Text** 3가지를 제공합니다.
    • **추천 방식**: Raw HTML 모드에서 기본 구조를 입력한 후, Summernote 모드로 전환하여 시각적 수정을 진행합니다.
    • Summernote 에디터 내에서 이미지를 업로드하고 즉시 편집할 수 있습니다.
  • 이미지 업로드: 상품 이미지는 **최대 3장**까지 등록 가능합니다. (대표 이미지 포함)
  • 미리보기: 등록 전 실제 상품 상세 화면이 어떻게 노출되는지 확인합니다.
  • 등록 버튼으로 저장 완료

4-3. 상품 상세 정보

상품의 상세 스펙과 리뷰/문의 현황을 확인합니다.

  • 수정 버튼: 상품 정보 수정 화면으로 진입합니다.
  • 상태변경 버튼: 판매/품절 상태를 즉시 전환합니다.

4-4. 상품 정보 수정

상품명, 가격, 설명 등을 업데이트합니다.

  • 수정 완료 후 **확인** 버튼을 클릭하여 반영합니다.

4-5. 상품리뷰관리

구매 고객이 작성한 리뷰를 모니터링하고 관리합니다.

  • 리뷰 내용과 평점을 확인하며, 부적절한 게시물은 관리 정책에 따라 제어합니다.
  • 삭제 버튼 클릭 시 해당 리뷰는 쇼핑몰 상세 페이지에서 즉시 **숨김 처리**되어 고객에게 보이지 않습니다.

4-6. 상품문의관리

상품에 대한 고객의 질문에 신속하게 답변을 등록합니다.

  • 답변 버튼을 클릭하면 답변을 입력할 수 있는 창이 나타납니다.
  • 내용 작성 후 확인을 누르면 상태가 **답변완료**로 변경되며 고객이 답변을 확인할 수 있습니다.

주문 및 통합 배송

전체 지점의 주문 내역을 실시간으로 추적하고 통합 배송 관리를 수행합니다.

5-1. 통합 주문 조회

전체 주문 목록을 확인하고 즉각적인 배송 처리를 수행합니다.

  • 상세: 주문 상세 정보 및 결제 내역 확인 화면으로 이동합니다.
  • 입금확인: 택배사 및 운송장 번호를 입력한 후 클릭하면 **입금확인 완료**와 함께 상태가 **배송중**으로 즉시 변경됩니다.
  • 배송정보업데이트: 이미 입력된 택배사 또는 운송장 번호를 수정할 때 사용합니다.

5-2. 주문 상세 및 배송 처리

주문 상태에 따라 화면 하단에 노출되는 처리 버튼이 달라집니다.

상태: 배송준비중 (또는 결제완료)

송장 정보를 입력한 후 클릭하여 프로세스를 진행합니다.

  • 입금확인: 배송 정보(택배사, 송장번호) 입력 후 클릭하면 **배송중 상태로 변경됩니다.**
상태: 배송중

상품 전달이 완료된 후 최종 종결 처리합니다.

  • 배송완료: 최종 도착 확인 시 클릭하면 **배송완료 상태로 변경됩니다.**
  • 업데이트: 오입력된 배송 정보를 수정하여 반영합니다.

시스템 설정 및 게시판

시스템 공지사항 및 기본 환경을 설정합니다.

6-1. 공지사항 리스트

전체 공지사항 목록을 조회하며 등록 버튼으로 신규 작성을 시작합니다.

6-2. 공지사항 상세 및 수정

게시된 내용을 확인하거나 수정합니다.

  • 내용 확인 후 **수정** 버튼을 통해 내용을 변경하거나 **삭제**할 수 있습니다.
