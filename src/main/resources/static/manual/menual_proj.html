상품 관리

본사에서 공급하는 상품 리스트를 확인합니다.

권한 안내
지점 판매자는 상품의 **신규 등록 및 내용 수정 권한이 없습니다.**
상품의 상세 스펙과 가격 정보만 조회 가능합니다.

2-1. 상품 리스트 조회

현재 판매 중인 전체 상품 목록을 조회합니다.

2-2. 상품 상세 정보

상품명 또는 상세 버튼을 클릭하여 상품의 상세 이미지와 정보를 확인합니다.

주문 관리

내 지점에서 발생한 주문 건에 대해 입금 확인 요청 및 정산 확정 업무를 수행합니다.

3-1. 주문 목록 조회

지점별 주문 발생 내역을 실시간으로 확인합니다.

3-2. 주문 상세 및 정산 요청

주문 상세 화면 하단에서 정산 관련 액션을 수행합니다.

  • 입금확인요청: 본사 송금 후 클릭하여 상태를 전환합니다.
  • 주문확정: 모든 배송 프로세스가 종료된 후 클릭하여 정산을 종결합니다.

게시판관리

본사의 공지사항을 확인하고 고객 리뷰/문의에 대응합니다.

4-1. 공지사항 확인

본사에서 게시한 중요 공지사항 목록을 확인합니다.

4-2. 상품 리뷰 관리

지점 상품에 달린 고객 리뷰를 모니터링합니다.

4-3. 상품 문의 대응

고객의 질문에 대해 답변 버튼을 클릭하여 소통합니다.
