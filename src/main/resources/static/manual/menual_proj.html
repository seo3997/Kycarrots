지점 판매자 메뉴얼

지점 판매자는 자신이 담당하는 지점의 상품 판매 현황을 확인하고, 본사와의 정산 및 주문 관리를 수행합니다.

1. 메인 화면 (대시보드)

지점 운영에 최적화된 대시보드를 통해 실시간 판매 현황과 본사 정산액을 모니터링합니다.

지점 관리자 핵심 업무
  • 정산 금액 확인: 이번 달 본사에 입금해야 할 총 원가(Cost) 실시간 집계
  • 입금확인요청 본사에 원가 송금 완료 후 클릭하여 본사 관리자에게 입금 확인을 요청합니다.
  • 주문확정 배송 완료된 건에 대해 최종적으로 클릭하여 해당 주문의 정산 데이터를 확정합니다.
  • 실시간 주문 모니터링: 내 지점에서 발생한 신규 주문 내역 즉시 확인 (주문번호 클릭 시 상세 화면 이동)

2. 상품 및 커뮤니티 관리

본사에서 공급하는 상품 정보를 조회하고, 고객의 리뷰 및 문의에 성실히 답변합니다.

상품 정보 조회 고객 피드백 대응 (리뷰/문의)

고객이 남긴 상품 리뷰와 Q&A를 주기적으로 확인하여 지점의 신뢰도를 높입니다.

3. 주문 및 고객 관리

지점 구매자들의 주문 내역을 상세히 관리하며, 배송 상태를 추적합니다.

주문 상세 관리

주문 상세 화면에서 고객의 배송지 정보를 확인하고, 입금 및 배송 진행 상황을 본사와 협업하여 관리합니다.

4. 실시간 Push 알림 수신

알림 수신 항목
  • 신규 주문 발생: 구매자가 결제를 완료하면 즉시 모바일 앱으로 알림이 전송됩니다.
  • 입금/배송 완료: 본사에서 입금 확인 및 배송 처리를 완료하면 지점에 결과가 공유됩니다.
  • 신규 문의 등록: 고객이 상품 문의(Q&A)를 남기면 즉시 알림이 발송되어 신속한 답변이 가능합니다.
